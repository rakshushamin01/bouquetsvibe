## ✨ Features Included

1. **Homepage Hero Banner:**
   - Brand value proposition & taglines
   - Express same-day delivery badges
   - Quick action buttons (Explore Catalog, Custom Builder, WhatsApp Order)

   - Categorized tabs (Wedding & Bridal, Birthday, Romance, Corporate, Care & Sympathy)

   - Step 4: Add-Ons (Ferrero Rocher, Teddy Bear, LED String Lights, Greeting Card)
   - Step 5: Card Message Textarea
   - Real-time price calculator & live preview image

4. **Services Showcase:**
   - Custom Floral Design
   - Same-Day & Midnight Express Delivery in Anekal
   - Wedding & Grand Event Decor (Mandaps, Arches, Car Decor)
   - Corporate & Office Floral Subscriptions

5. **About The Shop:**
   - Founding story on Shankarnag Road, Anekal
   - 100% Fresh Daily Harvest commitment
   - Artisanal craftsmanship & local community focus

6. **Gallery & Portfolio:**
   - Filterable photo showcase of past wedding decor, luxury boxes, and hand-tied bouquets

7. **Testimonials & Reviews:**

## 🚀 How to Run Locally

### Method 1: Double-Click Launcher (Windows)
Double-click `start_website.bat` in the project folder. It will launch a local server at `http://localhost:8000` and open it in your default browser.

### Method 2: Python HTTP Server (Terminal)
```bash
cd the-bouquets-vibe
python -m http.server 8000
```
Then open `http://localhost:8000` in your web browser.
